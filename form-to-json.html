Content Insertion Hints

        

            Insert an Image:

            <img src='images/articles/your-image.jpg' alt='description'>

            
Use this to insert an image into your content. The src attribute specifies the path to the image file, and the alt attribute provides a text description for accessibility and SEO.

        

        

            Insert a Video:

            <video src='images/articles/your-video.mp4' controls></video>

            
This tag embeds a video into your page. The src attribute points to the video file, and the controls attribute adds play/pause controls for the user.

        

        

            Create a Link:

            <a href='https://your-link.com'>Your Link Text</a>

            
This creates a hyperlink. The href attribute defines the URL to which the link points, and the text between the tags is what users will see and click on.

        

        

            Insert a Paragraph:

            <p>Your paragraph text here.</p>

            
Use this tag to insert a block of text. The <p> tag defines a paragraph, which will be displayed as a block of text with some spacing above and below.

        

        

            Insert an Image with Enhanced Attributes:

            <img src='images/articles/your-image.jpg' alt='description' width='500' height='300' loading='lazy'>

            
This version of the image tag includes additional attributes for better control: width and height specify the size of the image, and loading="lazy" defers loading the image until it's near the viewport, improving page load times.

        

        

            Insert a Video with Enhanced Attributes:

            <video src='images/articles/your-video.mp4' controls width='640' height='360' poster='images/articles/your-poster.jpg'>Your browser does not support the video tag.</video>

            
This enhanced video tag includes attributes for better control and user experience: width and height specify the video size, and poster shows an image (like a thumbnail) before the video is played.

        

        

            Create a Link with Enhanced Attributes:

            <a href='https://your-link.com' target='_blank' rel='noopener noreferrer' title='Visit Your Link'>Your Link Text</a>

            
This enhanced link includes additional attributes for better functionality: target="_blank" opens the link in a new tab, rel="noopener noreferrer" improves security, and title provides additional information when the user hovers over the link.
